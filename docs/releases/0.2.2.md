日期：2026-10-30（Asia/Shanghai）。版本 0.2.2，build 4，Apple Silicon（arm64），最低要求 macOS 13.0。中文输入与翻译体验继续作为早期版本打磨。

## 下载安装

[下载已公证 ZIP](https://github.com/jiaqianjing/monkey/releases/download/v0.2.2/Monkey-0.2.2-macos-arm64-notarized.zip)，解压后双击 **Monkey Installer.app**，点击 **安装**。安装完成后，从菜单栏输入法菜单选择 **Monkey 拼音**。

新版不再要求用户运行裸 `Install.command`，也不需要到系统安全设置手动添加打开例外。macOS 仍可能显示正常的首次下载打开确认。旧的 0.2.1 预览附件保留用于回退；请优先使用本页的新版下载。

## 本次改动

- 输入法、随包运行库和原生安装器改用 Developer ID Application 正式签名，启用 Hardened Runtime 与安全时间戳。
- 先完成输入法的 Apple 公证并附加票据，再封装到安装器，完成安装器自己的公证并附加票据。ZIP 解压后的两个应用均验证通过。
- 图形安装器仅写当前用户的 `~/Library/Input Methods/Monkey.app`，无需 `sudo`。个人词库、偏好与账号数据不在替换范围内。
- 更新前只请求安装目标路径的旧进程正常退出；增加完整性与团队身份检查、并发保护、版本降级检查和失败恢复。无法安全恢复时保留备份并给出路径。
- 安装完成后提供设置与键盘设置入口，不自动切换当前输入源。
