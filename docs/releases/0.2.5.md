# Monkey 0.2.5 · 切换英文时原样上屏

日期：2026-11-04（Asia/Shanghai）。版本 0.2.5，build 7，Apple Silicon（arm64），最低要求 macOS 13.0。

中文输入时，按 `Shift + Space` 或从菜单切换英文，会先将尚未上屏的键入内容按原文输出，再切换到英文直输。例如输入 `nihao` 后切换，上屏 `nihao`。翻译模式下会保留已确认的中文草稿、取消旧翻译请求；切回中文时翻译模式仍开启。
