# Monkey 0.2.6 · ChatGPT 连接管理

日期：2026-11-04（Asia/Shanghai）。版本 0.2.6，build 8，Apple Silicon（arm64），最低要求 macOS 13.0。

## 改动

- 新建 ChatGPT 授权时，使用 macOS 电脑名作为连接名的一部分；已有连接重新登录不会自动改名。先前未完成的授权可能被复用。
- 设置中可以删除指定连接在本机的记录和钥匙串凭据，并尝试撤销可续期会话。ChatGPT 中的旧关联仍需在 ChatGPT 设置中手动断开。
- 加强跨进程连接记录的同步和读取失败处理，减少同时管理不同连接时覆盖记录的风险。
- 包含 0.2.5 的中英文切换功能：中文输入时按 `Shift + Space` 会先将未上屏的输入按原文输出，再切换到英文直输。
