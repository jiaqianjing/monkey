# Monkey 0.1.0 开发预览

首次交付日期：2026-10-29（Asia/Shanghai）。

## 内容

- 原生 InputMethodKit 输入法，本地全拼、简拼、整句候选、中文标点与用户词学习。
- 基于雾凇拼音的约 90 万行词库数据；预编译词库随应用分发。
- Shift + Space 中英文切换；Control + Shift + T 开关中译英。
- 当前中文草稿的流式英文预览，Control + Return 确认英文，Shift + Return 输入中文。
- 官方 Sign in with ChatGPT、模型选择、Keychain 凭据保存与刷新。
- 设置界面中的翻译试写、自然日常 / 简洁商务语气。

## 已验证

- 本机 macOS 27.0.1 / Apple Silicon：完整 `swift test` 共 18 项通过。
- 真实 librime 测试覆盖全拼、简拼、整句、标点及重启后用户词排序学习。
- 登录协议、实际 RSA 身份签名校验、凭据刷新互斥、真实本地 HTTP/SSE 传输及草稿过期响应拒绝测试通过。
- GitHub Actions 已在干净环境完成依赖准备、测试、release build 和安装归档。
- 本机安装到用户输入法目录，macOS 注册、启用成功。
- 用户亲自在 TextEdit 选择 Monkey、输入 `nihao`，确认出现候选并通过空格输入“你好”。
- 用户完成官方浏览器登录与订阅授权；应用成功取得账号模型目录。
- 设置界面中完成真实订阅翻译，内置示例得到：`I’m free tomorrow afternoon. Let’s move the meeting to 3:00 p.m.`
- 发布归档解压后验证代码签名完整、运行库齐全、预编译词库及安装脚本路径正确。

## 交付边界

- 安装包为 Apple Silicon（arm64），最低构建版本 macOS 13.0；尚未在 macOS 13 或 Intel 实机验收。
- 为 ad-hoc 签名的开发预览，尚未经过 Apple 公证。
- ZIP 包含完整安装器，可以独立安装。当前开发机系统镜像服务失败，未提供 DMG。
- 跨应用兼容性、长时间日常输入和全面的中文候选质量仍需后续试用。
- 翻译模式首版按当前句子追加和回删；不承诺任意宿主中跨已提交段落的自动重写或撤销。
