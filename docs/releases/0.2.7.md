# Monkey 0.2.7 · 中/英键切换时原样上屏

日期：2026-11-05（Asia/Shanghai）。版本 0.2.7，build 10，Apple Silicon（arm64），最低要求 macOS 13.0。

## 改动

中文输入过程中，使用 macOS 的中/英键切换到英文键盘时，Monkey 尝试先将未上屏的键入内容按原文输出。`Shift + Space` 的输入法内部切换仍可使用，ChatGPT 连接管理功能保持不变。中/英键切换需要在 macOS 输入法设置中启用。

输入法根据系统当前输入源和前台应用判断是否正在切换；macOS 的回调顺序在不同场景中可能不同，状态不明确时保留原有的中文提交行为。系统按文稿自动切换输入源、其他应用及翻译草稿等场景仍需进一步验证。
