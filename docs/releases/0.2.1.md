# Monkey 0.2.1 输入与翻译体验预览

日期：2026-10-29（Asia/Shanghai）。

## 图标与设置

- 新增 macOS ICNS 与带透明通道的主图标，以立体青柠键帽、双拱和光标呼应「盲 key」。输入源菜单采用同源单色标记。
- 设置界面同步更新品牌标识、排版、层次和深浅模式，不再使用「猴」字作为图标。
- [资源与生成提示词](../brand.md)。

## 日常输入

- 候选窗口收紧为拼音、候选与小型工具栏；直接显示中译英按钮和设置齿轮，无需深入菜单寻找。
- 设置首页突出三步翻译引导，提供账号连接、翻译试写的直接入口。
- 只有拼音组合或未确认中文草稿存在时显示悬浮窗；激活输入法、空切换模式、提交完成均不留下空窗。Escape 收起窗口并保留已选好的中文草稿。
- 翻译模式下 Return 提交中文草稿及当前中文候选，不额外换行。Control + Return 仍只确认完成的英文；Shift + Return 保留为中文确认别名。
- 无组合内容时 Return 交给宿主应用处理；普通拼音模式的 Return 仍保留原始拼写，避免改变英文直输习惯。
- 正在输入拼音时点击中译英，会把当前中文候选带入翻译草稿。

## 翻译等待

- 本地停止输入等待由 650 ms 缩短为 250 ms；编辑、确认或切换焦点仍会取消过时请求。
- 增加可关闭的「响应优先」，不替换用户选中的模型。对官方明确支持 `reasoning.effort=none` 的精确模型名 `gpt-6.1-terra` 使用该参数；其他模型不发送额外推理参数。依据：[OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-terra)。
- 翻译试写显示首段英文及完整结果的耗时；耗时数据仅在内存中存在，不记录原文、账号、令牌或请求内容。
- 上述改动减少本地等待和不必要的准备操作，网络与服务端等待仍需实际观测，不能承诺固定响应时间。

## 钥匙串访问

旧版本在账号状态刷新、切回输入框及请求准备时多次读取钥匙串。0.2.1 将账号标签读取与凭据访问分离，并在内存中缓存当前账号凭据，轮换或退出后失效。

自动翻译使用非交互式读取。实机发现旧式 login 钥匙串可能忽略单次查询的无 UI 标志，因此又为所有 Monkey 钥匙串操作增加后台串行队列：自动操作期间暂时禁用该进程的钥匙串交互，并在成功或失败后恢复原策略。明确的授权操作排队执行，不能与临时策略竞争。若系统需要确认，则保留原文并引导至设置，后续按键不会反复要求授权。由用户主动点击「允许钥匙串访问」后，才允许系统显示授权面板。钥匙串操作移出输入法主线程，刷新令牌仍受跨进程锁保护。

当前发行包仍为 ad-hoc 签名。不同构建的代码身份会变化，因此更新后系统仍可能要求重新确认访问；这与每次打字反复读取是两个问题。凭据继续保存在 Monkey 自己的钥匙串项目中，未放宽访问权限。

## 本机服务请求观测

同一条内置公开示例、同一 GPT-6.1 Terra 模型，在钥匙串授权完成后测得：

| 请求参数 | 首段英文 | 完成 |
| --- | ---: | ---: |
| 响应优先 | 2.1 秒 | 2.3 秒 |
| 模型默认 | 3.6 秒 | 4.0 秒 |
| 响应优先复测 | 2.3 秒 | 2.8 秒 |
| 最终整合包，授权后 | 3.7 秒 | 4.3 秒 |
| 最终整合包，连续试译 | 2.1 秒 | 2.4 秒 |

这是五次本机请求的观测，含网络与模型时间，不含选词、250 ms 本地等待、首次钥匙串授权或凭据准备。响应优先的完成时间仍在 2.3～4.3 秒之间波动，不能据此宣称稳定倍数提速；网络波动、服务负载和缓存均可能影响结果。测试中也实际发现旧项目读取在授权前阻塞，这段等待不包含在表内。

## 验证

- 本机 `swift test`：49 项通过，包含真实 Rime、中文整段及高亮候选确认、缺失/拒绝凭据缓存、账号切换与过时读取隔离、原有流式传输和翻译草稿测试。
- 使用经典钥匙串的 no-UI 兼容参数时，当前 SDK 会报告经典钥匙串相关的已知弃用警告；同时传入建议的新式非交互 LAContext，保留旧参数用于旧连接的兼容。
- 独立候选布局预览与实际输入法按键分别记录，不用自动测试替代实体键盘及跨应用验收。
- 本机原生窗口已检查紧凑候选、翻译展开，以及设置首页的深浅外观、翻译页与账号入口；检查过程未更改系统外观。设置布局预览使用真实界面，未触发账号授权或联网动作。
- 最终安装包的冷启动试译已验证：旧钥匙串项目需要重新授权时立即返回应用内说明（本机状态码 -25293），连续重试不再次等待系统窗口，原文保留。主动授权仍由用户本人完成；普通拼音不需要该授权。
- 用户对最终安装包主动授权后，连续两次真实订阅翻译均完成，期间未再次出现钥匙串授权请求。
- 2026-10-29，用户通过实体键盘确认：在普通文本框中选择 Monkey、开启中译英后，输入 `nihao` 并直接按 Return，只上屏“你好”，没有额外换行，悬浮窗随即收起。输入目标的具体应用名称未记录；此结果不代表其他应用或全部输入场景均已验收。
