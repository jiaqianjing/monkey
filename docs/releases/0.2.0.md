# Monkey 0.2.0 中文输入体验预览

日期：2026-10-29（Asia/Shanghai）。

## 改进

- 增加 117 条日常词频补充；`nh`、`xx`、`hd` 首选为“你好”“谢谢”“好的”。继续使用 Rime 的词频和本机学习排序，没有把候选位置写死。
- 简拼改用独立的缩写拼写类别；常见换位、漏键、重复键以低于精确拼音的可信度参与纠错。没有默认开启 n/l 或平翘音混淆。
- 补充固定版本的英文及中英词数据，中文词典、英文表和混输表分别排序；`U盘`、`T恤`、`B站` 等可通过拼音选词。
- 新增生产组合输入层：网址、邮箱、小数、IP、版本号保留 ASCII 符号；已知产品保留显式大小写；英文分词空格可配置；Return 原文确认不额外换行。
- 保护 `mainaifen`、`bing`、`baidu` 等中文，不因英文词前缀提前切走；数字仍能选中文候选，中间编辑使用真实组合光标。
- 数字可接中文拼音，如 `2026nian`；kg、GB、fps 等单位保留英文。
- 默认紧凑横排候选，可改竖排；控件在逐键更新时复用。提供鼠标翻页及中文候选的个人学习记录清除操作，内置词库保留。
- 新增“中文输入”设置页。普通中文会话不读取 ChatGPT 登录凭据；联网翻译仍通过原有显式翻译模式使用。

## 已完成的验证

- 本机完整 `swift test`：36 项通过，包含真实 Rime、学习与重启、清除学习记录、原有登录/流式传输及翻译草稿测试。
- 固定主语料 89 条：首选 73→83（82.0%→93.3%），前五 78→84（87.6%→94.4%）；12 个错拼均首选正确。
- 额外 150 个精确拼音样本：前后均 144 个首选、150 个前五，逐项首选与排名未退化。
- 生产组合层 18 个字面保留场景在确认后全部精确通过；包含 `first.last+tag@example.co.uk`、`macOS 13`、`Python 3.12`、`API v2`。
- 五份对照报告使用同一 release runner、相同冻结语料；记录二进制与源码哈希，不读取用户实际输入或词库。

## 已知边界

- 纠错增加了部分按键的计算时间：本机固定语料的引擎处理 P95 由 1.221 ms 增至 7.970 ms，P99 为 18.005 ms。它不是系统端到端输入延迟，仍需持续监测。
- “两点/亮点”“再/在”等上下文同音选择仍有不足。
- 完全无选词边界的中英长串尚未自动拆分成功，例如 `wozaiyongmacOS`。当前应先确认中文候选，再继续输入英文或数字。
- 本轮界面和实体键盘检查遇到 Mac 锁屏，尚未完成。候选布局预览使用独立临时词库，不能当作真实按键或跨应用验收。
- Apple Silicon / macOS 13.0+ 构建，ad-hoc 签名、未经过 Apple 公证；较旧系统和其他设备仍待实际验证。

以上结果是 Monkey 自身前后对照，没有微信或搜狗同条件数据，不能据此宣称追平或超过它们。
