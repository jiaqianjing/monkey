# 隐私边界

Monkey 的普通中文拼音输入在本机通过 librime 完成。联网翻译由明确的翻译模式触发；当前句子的中文草稿、选择的表达偏好及必要的翻译指令会发送给 OpenAI。

应用不会为了翻译主动收集整个文档、剪贴板、屏幕或其他应用内容，也不会通过 ChatGPT 登录读取用户的 ChatGPT 历史会话。它能使用的上下文以当前输入会话和实际请求内容为准。

ChatGPT 登录在系统浏览器中完成，Monkey 不接收密码或验证码。授权后的凭据保存在 macOS Keychain。“退出登录”会删除本机凭据并保留连接记录，方便以后重新登录；“删除已保存连接”会同时删除该连接的本机记录和凭据，下次登录可能继续使用之前未完成的授权，也可新建连接。这两项操作都会尝试撤销当前可续期的登录会话；如需移除 ChatGPT 中的应用关联，仍须到 ChatGPT 设置的“安全与登录 → 使用 ChatGPT 登录”中断开。卸载应用本身不等于撤销云端授权。

新建 ChatGPT 授权时，Monkey 会将 macOS 的电脑名称用于连接名称（例如 `Monkey · MacBook Pro`）并提交给 OpenAI，便于区分设备。已有连接重新登录会复用原连接，名称不会因此更新。

普通输入和联网翻译的边界应在界面中清楚可见。取消翻译会停止本机采用结果；已发送到 OpenAI 的请求不能被解释为从未发送。

本地用户词学习、偏好和登录连接默认保留，不随应用升级或卸载自动清理。报告问题时应避免附带账号令牌、真实敏感句子或 Keychain 内容。

OpenAI 服务的数据处理、额度和可用性由其服务条款与账号设置决定。`store: false` 是本接入的请求要求，不应被宣传为所有服务数据处理过程都不存在保留。
