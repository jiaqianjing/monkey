# 首版验收

以下是手工验收清单，不是已经通过的测试报告。需要记录系统版本、应用版本、输入目标、实际结果及尚未解决的问题。

## 构建与安装

- `swift test` 完成并报告最终结果。
- app 内所有非系统依赖完整，签名验证通过。
- 从发行 ZIP 或 DMG 在本机完成安装，TIS 可找到输入源。
- 安装不自动切换当前输入源；可手动选中 Monkey。
- 首次安装或更新后，必要时注销再登录并重新验证。

## 中文输入

在 TextEdit、浏览器输入框和 Electron 聊天应用中分别检查：

拼音测试应使用真实键盘或逐个键码事件。粘贴字符串、直接设置文本值或部分自动化工具的 Unicode 文本插入会绕过输入法，不能作为拼音按键转换的验收证据。

- 全拼、简拼、长句、数字选词、空格选词、翻页、退格。
- 中英文与数字混输、标点、常用人名、产品名。
- 切换应用、切换输入法、关闭输入框不会串会话或丢失已提交文字。
- 离线仍能持续输入；学习词只影响 Monkey 自己的用户词库。

## 翻译

- 用户自己完成浏览器登录及订阅授权。
- 账号目录返回可选模型，并至少完成一次真实中译英。
- 预览响应时延记录实际数值，不能用模拟响应作为网络时延证据。
- `Control + Return` 只在当前译文已完成时上屏，宿主不会同时收到发送动作。
- 翻译模式下 `Return` 可直接上屏中文，不额外换行；`Shift + Return` 保留为别名。无组合内容时 Return 交给宿主应用；Esc 不丢弃需要保留的草稿。
- 修改中文使旧译文失效，切焦点后迟到响应不写入新输入框。
- 断网、失效凭据、额度不足、流中断时明确显示状态并保留原文。

## 表达质量

用一组固定但不含敏感信息的句子检查聊天、邮件、工作表达。重点保留否定、时间、数字、产品名和语气；翻译应忠实表达，不扩写事实或回答句子中的提问。

## 发行边界

签名、公证与安装是不同阶段。开发机运行成功不代表已在 macOS 13、Intel Mac 或其他用户账号上验证。未完成的环境应标为待验证。

## 0.2.1 已完成的实体键盘检查

2026-10-29，用户在本机对已安装的 0.2.1 版本亲自操作并确认：选择 Monkey 拼音，按 `Control + Shift + T` 开启翻译，输入 `nihao` 后直接按 Return，结果只上屏“你好”，没有额外换行，悬浮窗随即收起。

此项来自用户的实体键盘反馈，具体宿主应用名称未记录。它确认了这一条中文回车与收窗流程，不替代长句、其他宿主应用、英文确认及其他边界场景的验收。
