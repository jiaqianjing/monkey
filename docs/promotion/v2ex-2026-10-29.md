# [开源] Monkey：macOS 拼音输入法，支持复用 ChatGPT 订阅的中译英

最近做了一款 macOS 原生中文输入法 Monkey，刚发布 0.2.1 开发预览，想找愿意尝鲜的朋友一起打磨日常输入。名字也是一个“盲 key”的谐音，希望少打断写作，多把注意力留在内容上。

它用 Swift / InputMethodKit 做系统输入法，底层是 librime 和雾凇拼音。普通拼音、候选排序及用户词学习在本机完成，无需登录。支持全拼、简拼、常见错拼纠正和中英词候选，网址、邮箱、小数与版本号会尽量保留 ASCII 符号。

另外想做的是：**用中文组织表达，在当前输入框里预览英文，确认后再上屏**，减少在翻译工具和聊天窗口之间复制粘贴。

- `Control + Shift + T`：开启中译英，也可直接点候选条上的按钮。
- 正常拼音选词组成中文草稿，等待英文预览。
- `Control + Return`：确认英文；翻译模式下直接 `Return`：提交中文。
- 候选窗只在输入或有待确认草稿时出现，提交后收起。

翻译使用官方 Sign in with ChatGPT，符合条件的订阅账号可授权使用额度，无需填写 API key。模型、资格与额度由账号和服务决定，不是无限调用，也不会带入 ChatGPT 聊天记录。只有主动开启翻译后，当前草稿和表达偏好才会发送给 OpenAI，凭据保存在 macOS Keychain。

0.2.1 主要打磨了候选条上的翻译、设置入口和回车行为，也换了青柠色键帽图标、重做了设置引导。翻译等待做了优化，但网络与模型耗时仍有波动，暂不承诺固定速度。

目前提供 **Apple Silicon / macOS 13+** 安装包，使用 ad-hoc 签名，**尚未经过 Apple 公证**，仍是开发预览。解压后运行 `Install.command`，安装到当前用户的输入法目录，不需要管理员密码，再手动选中 Monkey；部分情况下需要注销重新登录。仓库提供源码构建和卸载说明。

中文上下文同音排序、无分隔中英长串和跨应用兼容仍需继续打磨。当前混输建议先确认中文候选，再接英文或数字。原创代码是 MIT；librime、词库及其他依赖保留各自许可证，雾凇数据含 GPL-3.0，来源与声明随仓库提供。
