# 做了个能边写边译的Mac输入法

最近在做一款 macOS 中文输入法，叫 Monkey，也藏了个“盲 key”的谐音梗：希望眼睛留在内容上，少为输入来回切换。

最想解决的是写英文消息时的打断感。先用中文组织表达，在当前输入框里看英文预览，确认合适再上屏。

⌨️ Control＋Shift＋T 开启中译英
↗️ Control＋Return 确认英文
↩️ 翻译模式下，直接 Return 仍可提交中文

这次放出了 0.2.1 开发预览：
· 基于 Rime 和雾凇词库，普通拼音、候选排序与本机学习离线完成。
· 打磨常见错拼、日常词频和中英混输，网址、邮箱和版本号尽量保留原样。
· 候选条能直接开翻译、进设置，提交后收起。
· 换了青柠色键帽图标，设置界面也重新整理了。

翻译走官方 ChatGPT 登录，符合条件的订阅账号可授权使用，不用填 API key。额度、模型以账号实际返回为准，不会读取 ChatGPT 聊天记录；只有主动开启翻译后，当前中文草稿才会发送给 OpenAI。

目前是 Apple Silicon / macOS 13+ 开发预览包，ad-hoc 签名、尚未公证。中文同音排序和跨应用兼容还要继续磨；有些混输需要先选好中文，再接英文与数字，适合愿意反馈问题的朋友试用。
