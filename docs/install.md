# 安装 Monkey

适用于 **M 系列芯片的 Mac · macOS 13 及以上**。普通中文输入无需登录。

## 三步开始打字

1. **下载并解压**：[下载 macOS 安装包](https://github.com/jiaqianjing/monkey/releases/download/v0.2.3/Monkey-0.2.3-macos-arm64-notarized.zip)。
2. **点击安装**：双击解压后的 **Monkey Installer.app**，点击 **安装**。
3. **切换输入法**：在菜单栏输入法菜单中选择 **Monkey 拼音**。

现在输入 `nihao`，按空格，就能打出“你好”。

安装包已通过 Apple 公证，首次打开时按 macOS 的正常提示确认即可。

## 开启中译英（可选）

点击安装器里的 **打开 Monkey 设置**，选择 **Continue with ChatGPT** 完成连接。之后在输入框中：

- `Control + Shift + T`：开启中译英。
- 输入中文，等待英文预览完成。
- `Control + Return`：输入英文；直接按 `Return` 则输入中文。

## 菜单里没有 Monkey 时

在 **系统设置 → 键盘 → 文字输入 → 编辑** 中添加 **Monkey 拼音**，再回到菜单栏切换。

如果仍未出现或无法输入，注销当前 macOS 用户后重新登录，再试一次。

## 更新

下载新版安装包，结束当前输入并关闭 Monkey 设置，再运行安装器。词库、设置和账号连接会保留。
